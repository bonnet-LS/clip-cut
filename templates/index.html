          수동 설치 방법 보기
          

            
            
          


          

            
    
              
  1. 
                Homebrew가 없다면 터미널(Spotlight에서 "터미널" 검색)에 아래 명령을 붙여넣어 설치
                
    
                  /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
                  
                
    
              
    2. 
              
  2. 
                설치가 끝나면 터미널에 아래 명령 입력
                
    
                  brew install ffmpeg
                  
                
    
              
    3. 
              
  3. 설치가 끝나면 이 페이지로 돌아와 "설치 확인" 버튼 클릭
    4. 
            


            

              ⚠ "Homebrew on macOS is only supported on Apple Silicon processors" 같은 오류가 뜨면,
              이 Mac은 Intel(x86_64) 프로세서이고 최신 Homebrew가 Intel 지원을 중단한 경우입니다.
              이때는 MacPorts(Intel을 계속 지원하는 공식 패키지 관리자)를 사용하세요.
              ffmpeg.org의 "소스 코드" 다운로드는 직접 컴파일이 필요해 피하는 것이 좋습니다.
            

            
    
              
  1. 
                MacPorts 공식 설치 페이지에서
                본인 macOS 버전에 맞는 .pkg 설치 프로그램을 받아 더블클릭 설치 (관리자 비밀번호 입력)
              
    2. 
              
  2. 
                터미널을 완전히 종료 후 다시 열고 아래 명령 입력 (비밀번호 재입력 필요, 수 분 소요)
                
    
                  sudo port selfupdate && sudo port install ffmpeg
                  
                
    
              
    3. 
              
  3. 설치가 끝나면 이 페이지로 돌아와 "설치 확인" 버튼 클릭
    4. 
            

          


          

            
    
              
  1. 
                Windows 10(1809 이상)/11이면 PowerShell 또는 명령 프롬프트에 아래 명령 입력
                
    
                  winget install --id=Gyan.FFmpeg -e
                  
                
    
              
    2. 
              
  2. 
                winget이 안 될 경우: ffmpeg 공식 빌드 다운로드에서
                "release essentials" zip을 받아 압축 해제 후, 그 안의 bin 폴더 경로를
                시스템 환경 변수 PATH에 추가
              
    3. 
              
  3. 설치가 끝나면 이 페이지로 돌아와 "설치 확인" 버튼 클릭
    4.
