ClipCut 사용설명서

영상을 고르고 자를 시간만 입력하면, 원하는 부분만 mp4 클립으로 잘라 주는 사내용 컷편집 도구입니다.

어떤 방법으로 쓸까요?

웹 버전 추천

  • 설치 없이 링크만 열면 바로 사용
  • Mac · Windows 모두 사용 가능
  • '정확하게'는 최대 Full HD(1920)로 저장

로컬 실행 버전

  • 4K 원본 화질 그대로, 더 빠르게 처리
  • 처음 한 번 Python 설치와 실행 파일 필요
  • 결과를 원하는 폴더에 바로 저장
어느 쪽이든 영상은 내 컴퓨터 안에서만 처리되며 외부 서버로 전송되지 않습니다.
웹 버전 안내

1. 열기

  1. Chrome 또는 Edge 브라우저에서 clipcut-tau.vercel.app 에 접속합니다.
  2. 처음 열 때 영상 처리 도구(약 30MB)를 불러오느라 몇 초 걸릴 수 있습니다.
자주 쓴다면 즐겨찾기에 추가해 두세요.

2. 영상 자르기

3. 결과 받기

  • 클립이 1개면 .mp4 파일, 여러 개면 영상이름_clips.zip 파일로 다운로드 폴더에 저장됩니다.
  • 완료 화면의 다시 다운로드로 한 번 더 받을 수 있습니다.
웹 버전의 한계: 브라우저 메모리 한계 때문에 '정확하게'로 자를 때는 최대 Full HD(긴 변 1920px)로 저장됩니다. 4K 원본 화질이 꼭 필요하면 로컬 실행 버전을 써 주세요. ('빠르게'는 4K 원본 그대로 저장됩니다.)

4. 문제가 생겼을 때

Mac 로컬 실행 안내

1. 처음 한 번만 준비하기

① Python 설치

  1. python.org/downloads 에 접속해 노란색 Download Python 버튼을 누릅니다.
  2. 받은 .pkg 파일을 더블클릭해 안내에 따라 설치합니다. (계속 → 동의 → 설치, Mac 비밀번호 입력)

② ClipCut 내려받기

  1. 전달받은 GitHub 주소에서 초록색 Code 버튼 → Download ZIP을 누릅니다. (ZIP 파일을 직접 받았다면 이 단계는 건너뜁니다)
  2. 받은 ZIP 파일을 더블클릭하면 폴더가 생깁니다. 이 폴더를 원하는 곳(예: 문서 폴더)으로 옮겨 둡니다.

2. 실행하기

  1. 폴더 안의 run_mac.command 파일을 더블클릭합니다.
  2. 터미널 창이 열리고, 처음 실행할 때만 필요한 구성요소를 내려받느라 1~2분 정도 걸립니다.
  3. 잠시 후 브라우저에 ClipCut 화면(http://127.0.0.1:5050)이 자동으로 열립니다.
"확인되지 않은 개발자" 또는 "열 수 없습니다" 경고가 뜨는 경우 (처음 한 번만)
  1. 경고 창에서 완료(또는 취소)를 누릅니다.
  2. 화면 왼쪽 위 Apple 메뉴 → 시스템 설정 → 개인정보 보호 및 보안으로 갑니다.
  3. 아래로 내려 "run_mac.command이(가) 차단되었습니다" 옆의 그래도 열기를 누릅니다.
  4. 다시 run_mac.command를 더블클릭하고 열기를 누릅니다.
"명령 라인 개발자 도구를 설치하겠습니까?" 창이 뜨면 Python이 설치되지 않은 상태입니다. 창을 닫고 ① Python 설치를 먼저 진행해 주세요.
터미널 창은 ClipCut을 쓰는 동안 닫지 마세요. 창을 닫으면 프로그램도 꺼집니다. 브라우저 창만 닫았다면 터미널에 표시된 주소(보통 http://127.0.0.1:5050)를 다시 열면 됩니다.

3. 영상 자르기

4. 결과 확인

  • 원본 영상이 있는 폴더 안에 영상이름_clips 폴더가 생기고, 그 안에 클립이 저장됩니다. ③ 출력 설정의 저장 위치 → 변경으로 다른 폴더를 고를 수 있습니다.
  • 완료 화면의 폴더 열기를 누르면 바로 확인할 수 있습니다.
  • 영상을 클릭해서 고르면 Mac 파일 선택 창이 뜹니다. 창이 안 보이면 Dock이나 다른 창 뒤에 가려져 있을 수 있습니다.

5. 끝내기

터미널 창을 닫으면 됩니다. "프로세스를 종료하겠습니까?"라고 물으면 종료를 누르세요.

6. 문제가 생겼을 때

Windows 로컬 실행 안내

1. 처음 한 번만 준비하기

① Python 설치

  1. python.org/downloads 에 접속해 노란색 Download Python 버튼을 누릅니다.
  2. 받은 설치 파일(.exe)을 실행합니다.
  3. 첫 화면 아래쪽의 "Add python.exe to PATH" 칸에 반드시 체크한 뒤 Install Now를 누릅니다.
"Add python.exe to PATH" 체크를 빠뜨리면 ClipCut이 Python을 찾지 못합니다. 이미 체크 없이 설치했다면 설치 파일을 다시 실행해 Modify → Next → "Add Python to environment variables" 체크 → Install 순서로 눌러 주세요.

② ClipCut 내려받기

  1. 전달받은 GitHub 주소에서 초록색 Code 버튼 → Download ZIP을 누릅니다. (ZIP 파일을 직접 받았다면 이 단계는 건너뜁니다)
  2. ZIP 파일을 마우스 오른쪽 버튼으로 클릭 → 모두 압축 풀기를 선택하고, 압축이 풀린 폴더를 원하는 곳(예: 문서 폴더)에 둡니다.
ZIP 파일을 더블클릭해서 압축을 풀지 않은 채 안에서 바로 실행하면 동작하지 않습니다. 꼭 압축을 풀어 주세요.

2. 실행하기

  1. 폴더 안의 run_windows.bat 파일을 더블클릭합니다.
  2. 검은 명령 창이 열리고, 처음 실행할 때만 필요한 구성요소를 내려받느라 1~2분 정도 걸립니다.
  3. 잠시 후 브라우저에 ClipCut 화면(http://127.0.0.1:5050)이 자동으로 열립니다.
"Windows의 PC 보호" 파란 창이 뜨는 경우 (처음 한 번만)
  1. 창 안의 추가 정보를 누릅니다.
  2. 실행 버튼을 누릅니다.
Microsoft Store가 열리거나 "Python이 설치되어 있지 않습니다"라고 나오면 Python이 제대로 설치되지 않은 상태입니다. ① Python 설치를 "Add python.exe to PATH" 체크와 함께 다시 진행해 주세요.
검은 명령 창은 ClipCut을 쓰는 동안 닫지 마세요. 창을 닫으면 프로그램도 꺼집니다. 브라우저 창만 닫았다면 명령 창에 표시된 주소(보통 http://127.0.0.1:5050)를 다시 열면 됩니다.

3. 영상 자르기

4. 결과 확인

  • 원본 영상이 있는 폴더 안에 영상이름_clips 폴더가 생기고, 그 안에 클립이 저장됩니다. ③ 출력 설정의 저장 위치 → 변경으로 다른 폴더를 고를 수 있습니다.
  • 완료 화면의 폴더 열기를 누르면 바로 확인할 수 있습니다.
  • 영상을 클릭해서 고르면 Windows 파일 선택 창이 뜹니다. 창이 안 보이면 작업 표시줄에서 찾아 주세요.

5. 끝내기

검은 명령 창의 X 버튼을 눌러 닫으면 됩니다.
