ClipCut 사용설명서

영상을 올리고 자를 시간만 입력하면, 원하는 부분만 mp4 클립으로 잘라 한 번에 받을 수 있는 프로그램입니다.

Mac 사용자용 안내

1. 처음 한 번만 준비하기

① Python 설치

  1. python.org/downloads 에 접속해 노란색 Download Python 버튼을 누릅니다.
  2. 받은 .pkg 파일을 더블클릭해 안내에 따라 설치합니다. (계속 → 동의 → 설치, Mac 비밀번호 입력)
💡 Python은 ClipCut이 돌아가는 데 필요한 기본 프로그램입니다. 한 번만 설치하면 됩니다.

② ClipCut 압축 풀기

  1. 전달받은 ClipCut.zip 파일을 더블클릭하면 ClipCut 폴더가 생깁니다.
  2. 이 폴더를 원하는 곳(예: 문서 폴더)으로 옮겨 둡니다.

2. 실행하기

  1. ClipCut 폴더 안의 run_mac.command 파일을 더블클릭합니다.
  2. 검은 터미널 창이 열리고, 처음 실행할 때만 필요한 구성요소를 내려받느라 1~2분 정도 걸립니다.
  3. 잠시 후 인터넷 브라우저에 ClipCut 화면이 자동으로 열립니다.
⚠ "확인되지 않은 개발자" 또는 "열 수 없습니다" 경고가 뜨는 경우 (처음 한 번만)
  1. 경고 창에서 완료(또는 취소)를 누릅니다.
  2. 화면 왼쪽 위 사과(Apple) 메뉴 → 시스템 설정 → 개인정보 보호 및 보안으로 갑니다.
  3. 아래로 내려 "run_mac.command이(가) 차단되었습니다" 옆의 그래도 열기를 누릅니다.
  4. 다시 run_mac.command를 더블클릭하고 열기를 누릅니다.
⚠ "명령 라인 개발자 도구를 설치하겠습니까?" 창이 뜨면 Python이 설치되지 않은 상태입니다. 창을 닫고 위의 ① Python 설치를 먼저 진행해 주세요.
💡 터미널 창은 ClipCut을 쓰는 동안 닫지 마세요. 창을 닫으면 프로그램도 꺼집니다. 브라우저 창을 실수로 닫았다면 주소창에 http://127.0.0.1:5050 을 입력하면 다시 열립니다.

4. 끝내기

터미널 창을 닫으면 됩니다. "프로세스를 종료하겠습니까?"라고 물으면 종료를 누르세요.

Windows 사용자용 안내

1. 처음 한 번만 준비하기

① Python 설치

  1. python.org/downloads 에 접속해 노란색 Download Python 버튼을 누릅니다.
  2. 받은 설치 파일(.exe)을 실행합니다.
  3. 첫 화면 아래쪽의 "Add python.exe to PATH" 칸에 반드시 체크한 뒤 Install Now를 누릅니다.
⚠ "Add python.exe to PATH" 체크를 빠뜨리면 ClipCut이 Python을 찾지 못합니다. 이미 체크 없이 설치했다면 설치 파일을 다시 실행해 Modify → Next → "Add Python to environment variables" 체크 → Install 순서로 눌러 주세요.

② ClipCut 압축 풀기

  1. 전달받은 ClipCut.zip 파일을 마우스 오른쪽 버튼으로 클릭 → 압축 풀기(모두 압축 풀기)를 선택합니다.
  2. 압축이 풀린 ClipCut 폴더를 원하는 곳(예: 문서 폴더)에 둡니다.
⚠ zip 파일을 더블클릭해서 압축을 풀지 않은 채 안에서 바로 실행하면 동작하지 않습니다. 꼭 압축을 풀어 주세요.

2. 실행하기

  1. ClipCut 폴더 안의 run_windows.bat 파일을 더블클릭합니다.
  2. 검은 명령 창이 열리고, 처음 실행할 때만 필요한 구성요소를 내려받느라 1~2분 정도 걸립니다.
  3. 잠시 후 인터넷 브라우저에 ClipCut 화면이 자동으로 열립니다. 화면이 비어 있거나 "연결할 수 없음"이 보이면 몇 초 뒤 F5(새로고침)를 눌러 주세요.
⚠ "Windows의 PC 보호" 파란 창이 뜨는 경우 (처음 한 번만)
  1. 창 안의 추가 정보를 누릅니다.
  2. 실행 버튼을 누릅니다.
⚠ Microsoft Store가 열리거나 "Python이 설치되어 있지 않습니다"라고 나오면 Python이 제대로 설치되지 않은 상태입니다. 위의 ① Python 설치를 "Add python.exe to PATH" 체크와 함께 다시 진행해 주세요.
💡 검은 명령 창은 ClipCut을 쓰는 동안 닫지 마세요. 창을 닫으면 프로그램도 꺼집니다. 브라우저 창을 실수로 닫았다면 주소창에 http://127.0.0.1:5050 을 입력하면 다시 열립니다.

3. 영상 자르기

4. 끝내기

검은 명령 창의 X 버튼을 눌러 닫으면 됩니다.
